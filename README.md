# v-card
My electronic business card to showcase my portfolio

## Live Site
Visit the live site at: https://arthurivan.github.io/v-card/

## About
This is a responsive single-page portfolio website built with:
- HTML5, CSS3, JavaScript
- jQuery with Isotope.js for portfolio filtering
- FontAwesome icons
- Responsive design for all devices

## Features
- Interactive portfolio with category filtering
- Smooth section transitions
- Animated skill progress bars
- Social media integration
- Contact information with WhatsApp link

## Deployment
This site is automatically deployed to GitHub Pages from the main branch.
